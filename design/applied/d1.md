# D1 適用記録

担当は描画用JS 8個、`web/css/design-d1.css`、この記録のみ。共通部品・版カタログ・HTML・生成データは変更していない。外部コード・画像・書体ファイルは取り込んでいない。

## 適用の範囲

- 資料は担当の `design/specs/*.json` と `design/rights/l1.md`〜`l4.md`。公開ページの再取得はしていない。各版の資料URLを画面の「この版の資料」と `data-spec-source` に付与。GPT-2は専用の操作欄を増やさず、URLを属性とアプリ共通の出典パネルへ委ねる。
- 全107版で色番号、領域の実測寸法、角丸の実測値、当日の専用書体はnull。既存テーマと基本寸法を維持し、新たに実測値と断定した色は足していない。新しい配置の相対幅・em単位・狭い画面での積み重ねは再描画の都合であり、歴史的な測定値ではない。
- 基本の会話・入力・窓・分割表示は既存の共通部品を利用。製品名は普通の文字。空の案内と質問例は自作の短い日本語。右欄などの生成物は空画面で固定せず、表示例の操作で開く。
- sourceがある機能でも、APIの仕様から専用画面を作らない。架空の完了件数、検証済み、遅延、費用、読み込み済みファイルを表示しない。
- 編集・表示の切替・並べ替え・送信は再現画面内の操作。導入、外部検索、マイク、ファイル添付、他社アプリへの書き出し等の多くは既存の資料パネルへつなぐ。この変更は実サービスへの接続実装ではない。表示例はその旨を表示。

## 版ごとの変更とキー

全版で `sources` と `must_not_copy` を適用し、`confidence` は新規の固有分岐を追加する判断に使用。下表の「変更」は `regions` の裏付けがある位置関係、`controls` の役割・短いラベル、`conversation` の区別、`empty_state` の確認済みの内容へ対応する。細かな動作の制約は各表の後に記載。
