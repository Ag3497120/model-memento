## 今回の合成処理

Model Memento 自身の小さな中継プログラムを MIT ライセンスで追加した。補助役への接続名は `helper-<role>`、道具名は `ask_<role>`。入力は `{ task: "依頼文" }`、結果は補助役の回答を含む文章。MCP の標準入力・出力通信は改行区切りの JSON を使い、標準出力には通信内容だけを書く。[MCP の通信仕様](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)

`planRecipe` は、アダプターが依頼と結果の受け渡しを明示する `asMcpServer`（返却値の `delegates: true`）を優先する。現在の既存サーバー3種類はその条件を満たさない。次に `headless`（画面を開かずに1回実行する設定）を使って中継を作る。どちらもなければ手動とし、PLAN.md に理由と出典を残す。進行役が MCP の道具を受け取れない場合も手動にする。道具を公開するだけの接続を作業委任として扱わない。[Claude Code の道具サーバー](https://code.claude.com/docs/en/mcp#use-claude-code-as-an-mcp-server)、[OpenClaw の会話サーバー](https://docs.openclaw.ai/cli/mcp/serve)、[Hermes の公開範囲](https://github.com/NousResearch/hermes-official-plugins/blob/main/mcp-serve/README.md)

設定案には `.config/helpers/<role>.bridge.json` を含める。アダプター名、実行ファイルと引数の配列、環境変数、作業場所（必ず `workspace/project`）、制限時間、出力量の上限、入力と回答の形式を保存する。この設定案に依頼文そのものや鍵の値は保存しない。環境変数の参照は実行時に起動元から読む。補助役の設定先は `.config/helpers/<role>-<index>/<harness>/`。中継はこの Model Memento の `server.js` と Node の絶対パスを参照するため、設定案を適用した後もこのコードを置いた場所が必要。

依頼は1〜20000文字。同じ役は同時に1件だけとし、同じ設定を使う別の中継プロセスにも実行中の確認を行う。制限時間は最大15分、出力量の既定値は標準出力と標準エラー出力を合計して1 MiB（設定上限8 MiB）。制限に達したら補助役を終了して日本語のエラーを返す。macOS/Linux では子孫のプロセスもまとめて終了する。Windows の子孫の終了は unverified。キャンセルや進行役との切断でも補助役を終了する。中継自体が強制終了されて残った `.lock` は自動削除しない。実行中の補助役がないことを確認してから対処する。

依頼文は標準入力、または一時ファイルで渡す。Aider は公式の `--message-file` を使い、依頼文の代わりにファイルの絶対パスだけを起動引数へ入れる。`--yes-always` や `-h` で始まる文章も、起動オプションとして渡らない。[Aider のファイル入力](https://aider.chat/docs/scripting.html)、[引数一覧](https://aider.chat/docs/config/options.html#--message-file-message_file)

一時ファイルは `.config/helpers/.task-<role>-<ランダムな文字>/task.txt` に UTF-8 で作る。macOS/Linux ではフォルダーを所有者だけが使える権限（0700）、ファイルを所有者だけが読み書きできる権限（0600）にする。保存先が作業フォルダー外へのリンクなら拒否する。回答を受け取ったとき、起動の失敗、時間切れ、出力量の超過、取り消し、接続切断のときに削除する。中継自体を強制終了すると残る場合がある。シェルは使わず、依頼文を起動引数へ直接入れる旧設定は拒否する。

補助役へ他の補助役の接続定義を渡さない。Claude Code は空の MCP 設定を明示し、pi は MCP を無効にする。Gemini CLI は個別の利用者設定に `mcp.allowed: []` を書く。既存のプロジェクト設定や管理者設定との優先順位、特に OpenCode が同じ作業場所から進行役用の設定を読み込む場合のモデル・提供元・中継の混在は実機で unverified。[Claude Code の引数](https://code.claude.com/docs/en/cli-reference)、[pi の引数](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/cli.md)、[Gemini CLI の設定](https://geminicli.com/docs/reference/configuration/)、[OpenCode の設定探索](https://github.com/anomalyco/opencode/blob/dev/packages/core/src/config/discovery.ts)

## 確認範囲とレビューで判断する点

実際の製品、モデル、Gateway、サーバーは起動していない。公開資料と、Node だけの偽プログラムを使ったオフラインテストで中継を確認した。実認証、実モデルの利用可否、各製品の現行版での接続、権限確認が必要な作業、実際の最終回答の形、長時間の運用、Windows は **unverified**。Aider は返答を含む出力をそのまま返すため、案内文から最終回答だけを分離する処理は **unverified**。[Aider の1回実行](https://aider.chat/docs/scripting.html)

ACP 用のクライアント（編集画面の代わりに通信する処理）は今回は実装していない。現在の対象には上表の非対話実行を使い、デスクトップ用の Antigravity は手動にした。ACP だけの実行環境を追加するときは、公開仕様と偽エージェントでのテストを別途用意する。

`test/recipes/helpers.test.js` の旧仕様6件を、中継を使う設定へ更新した。作業フォルダー内への保存、同じ実行ソフトを使う補助役ごとの設定先の分離、補助役同士の再呼び出し防止、各進行役が受け取る設定形式を確認する。画面を開かない実行方法が確認できない Antigravity は、手動の補助役として設定案を残す。

`test/recipes/bridge.test.js` では、画面なし実行に対応する全8種類について、各アダプターの実際の引数と入力方式を使い、起動先だけを偽プログラムへ置き換えて確認する。偽プログラムは知らないオプションを拒否する。`--yes-always`、`-h`、改行・日本語・絵文字・シェル用の記号を含む依頼文が、元の UTF-8 のバイト列と一致して届き、中継からそのまま返ることを検査する。実際の製品の引数処理やファイルの読み方は、実機で **unverified**。
