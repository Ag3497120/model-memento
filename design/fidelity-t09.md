# T09: Void evidence and fidelity

The catalog's three dates correspond to [v1.0.0](https://github.com/voideditor/void/releases/tag/v1.0.0), [v1.0.2](https://github.com/voideditor/void/releases/tag/v1.0.2), and [v1.3.4](https://github.com/voideditor/void/releases/tag/v1.3.4), respectively. The implementation is an independently written approximation based on the source, with no product artwork, icons or fonts.

| Edition | Evidence and screen |

For January, the [theme service](https://github.com/voideditor/void/blob/v1.0.0/src/vs/workbench/services/themes/common/workbenchThemeService.ts) names Default Dark Modern, whose [color file](https://github.com/voideditor/void/blob/v1.0.0/extensions/theme-defaults/themes/dark_modern.json) gives editor `#1F1F1F`, sidebar `#181818`, input `#313131`, text `#CCCCCC` and placeholder `#989898`. In [March](https://github.com/voideditor/void/blob/v1.0.2/src/vs/workbench/services/themes/common/workbenchThemeService.ts) and [April](https://github.com/voideditor/void/blob/v1.3.4/src/vs/workbench/services/themes/common/workbenchThemeService.ts), the default changes to Dark+. Its [included base theme](https://github.com/voideditor/void/blob/v1.0.2/extensions/theme-defaults/themes/dark_vs.json) sets editor `#1E1E1E`, text `#D4D4D4`, placeholder `#A6A6A6`; the [workbench default](https://github.com/voideditor/void/blob/v1.0.2/src/vs/workbench/common/theme.ts) supplies sidebar `#252526`. Theme variables and source-defined sizes are also recorded in the JSON spec.

[History](https://github.com/voideditor/void/blob/v1.0.0/src/vs/workbench/contrib/void/browser/react/src/sidebar-tsx/SidebarThreadSelector.tsx) is normally hidden and opens from the header; its empty-state text is reproduced. The source uses icon-only header actions, but the exhibit uses their action titles as text so no product icons are reproduced. The mode selector is visual only: changing it does not run Void's agent or tools. The warning represents a configuration without a provider; actual configured model names and default vary with setup. The shared museum model control is mounted in the composer slot.

Unverified: exact auxiliary-bar width and responsive behavior, operating system, actual keybinding on a viewer's platform, user-configured models, the open editor's sample content, actual rendering of inherited Dark+ input and border colors, and exact visual match. The editor file and code are illustrative, not claimed to be a product empty state. Widths, remaining colors, and responsive behavior are approximations. No browser or application was started for visual inspection. The test DOM checks structure and behavior, not pixels. `specPath` in the catalog and renderer registration in `index.js` are outside this task's allowed files.
