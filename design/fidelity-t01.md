# AionUi exhibit (X10)

The five snapshots use the catalog's own version tags, not an assumed current UI. The app is a visual desktop UI. No product art, icons, brand marks or fonts are copied. The product name is plain text; the controls use ordinary text and CSS shapes. User-provided configuration determines available assistants, skills, MCP servers and models; the exhibit does not invent model options.

## Source and reconstruction

- **v1.0.0 (2025-08-07):** [layout](https://github.com/iOfficeAI/AionUi/blob/v1.0.0/src/renderer/layout.tsx) gives the 250 px sidebar (64 px collapsed), 56 px header and light surface colors. [Main](https://github.com/iOfficeAI/AionUi/blob/v1.0.0/src/renderer/main.tsx) and [history](https://github.com/iOfficeAI/AionUi/blob/v1.0.0/src/renderer/conversation/ChatHistory.tsx) establish New Chat, history and Settings. [Welcome](https://github.com/iOfficeAI/AionUi/blob/v1.0.0/src/renderer/conversation/ConversationWelcome.tsx) and [English locale](https://github.com/iOfficeAI/AionUi/blob/v1.0.0/src/renderer/i18n/locales/en-US.json) establish the centered greeting, five-row composer, plus menu, file and folder labels and Enter behavior. The actual hover menu is represented by an accessible click disclosure. [Settings](https://github.com/iOfficeAI/AionUi/blob/v1.0.0/src/renderer/panel/geminsettings.tsx) establishes authentication settings but does not establish a model picker; its location is unverified.
- **v2.1.26 (2026-06-30):** [home](https://github.com/iOfficeAI/AionUi/blob/v2.1.26/packages/desktop/src/renderer/pages/guid/GuidPage.tsx), [CSS](https://github.com/iOfficeAI/AionUi/blob/v2.1.26/packages/desktop/src/renderer/pages/guid/index.module.css), [action row](https://github.com/iOfficeAI/AionUi/blob/v2.1.26/packages/desktop/src/renderer/pages/guid/components/GuidActionRow.tsx), [workspace control](https://github.com/iOfficeAI/AionUi/blob/v2.1.26/packages/desktop/src/renderer/pages/guid/components/GuidWorkspaceFootnote.tsx), [conversation locale](https://github.com/iOfficeAI/AionUi/blob/v2.1.26/packages/desktop/src/renderer/services/i18n/locales/en-US/conversation.json), and [home locale](https://github.com/iOfficeAI/AionUi/blob/v2.1.26/packages/desktop/src/renderer/services/i18n/locales/en-US/guid.json) establish the 800 px maximum centered home, 24 px card, lower-right model control, project control and the short conditional capability/skill/tool prompts. The exhibit illustrates a configured assistant and tools; their presence is conditional in the source.
- **v2.1.45 (2026-07-31):** [home](https://github.com/iOfficeAI/AionUi/blob/v2.1.45/packages/desktop/src/renderer/pages/guid/GuidPage.tsx), [conversation locale](https://github.com/iOfficeAI/AionUi/blob/v2.1.45/packages/desktop/src/renderer/services/i18n/locales/en-US/conversation.json), and [home locale](https://github.com/iOfficeAI/AionUi/blob/v2.1.45/packages/desktop/src/renderer/services/i18n/locales/en-US/guid.json) show the new task-oriented examples and a slash-command hint. The long examples are omitted; the hint is shown in the input. [Changelog](https://github.com/iOfficeAI/AionUi/blob/v2.1.45/CHANGELOG.md) also records the project explorer change, which is not represented on this empty home screen.
- **v2.1.61 (2026-08-25):** [home](https://github.com/iOfficeAI/AionUi/blob/v2.1.61/packages/desktop/src/renderer/pages/guid/GuidPage.tsx), [CSS](https://github.com/iOfficeAI/AionUi/blob/v2.1.61/packages/desktop/src/renderer/pages/guid/index.module.css), and [locale](https://github.com/iOfficeAI/AionUi/blob/v2.1.61/packages/desktop/src/renderer/services/i18n/locales/en-US/conversation.json) retain this home composition and slash hint. [Changelog](https://github.com/iOfficeAI/AionUi/blob/v2.1.61/CHANGELOG.md) records changes to the conversation and preview, including slash command acceptance and plan placement; those states are not simulated on the empty home screen.
- **v2.2.2 (2026-09-09):** [home](https://github.com/iOfficeAI/AionUi/blob/v2.2.2/packages/desktop/src/renderer/pages/guid/GuidPage.tsx), [CSS](https://github.com/iOfficeAI/AionUi/blob/v2.2.2/packages/desktop/src/renderer/pages/guid/index.module.css), and [locale](https://github.com/iOfficeAI/AionUi/blob/v2.2.2/packages/desktop/src/renderer/services/i18n/locales/en-US/conversation.json) continue the same home composition. The [release notes](https://github.com/iOfficeAI/AionUi/releases/tag/v2.2.2) describe changes to the Files/Changes explorer, which is not shown on the empty home screen. Similar appearance across these later snapshots is deliberate.

The models slot is mounted in the action row for the later versions; the host museum supplies its own selector and labels. The 1.0 screen has no asserted model picker. The project and attachment actions route to existing museum panels; they do not upload files or change a local folder.

## Limits

The later rail is 260 px by default in each tagged Layout.tsx; it is resizable in the August and September source. The tagged default-color-scheme.css supplies #f9fafb, #f2f3f5, #e5e6eb and other light tokens; each version-specific URL is recorded in the spec and disclosure. Some control colors, exact spacing, default assistant and available model list remain unverified. The short examples depend on a selected assistant and its data. Long later task examples and dynamically configured assistant names are omitted. This is a source-based reconstruction, not a pixel measurement or a running instance of the original application. Actual behavior of the product on a particular user's installation is unverified.

## OpenHuman exhibit (X14)

The source is a visual desktop application. Tag release dates match the eight catalog dates; July's `v0.63.9` precedes August's `v0.63.7` by release date. The following links identify the source for each reconstruction, not a claim of pixel accuracy. Text buttons stand in for product icons, and no product artwork or fonts are included.

- **March, v0.49.32:** [conversation](https://github.com/tinyhumansai/openhuman/blob/v0.49.32/app/src/pages/Conversations.tsx) supplies `Conversation`, `No messages yet`, `Model`, `Input`, `Text`, `Voice` and `Type a message...`; the selector sits above the composer and has `neocortex-mk1` as its fallback. [Sidebar](https://github.com/tinyhumansai/openhuman/blob/v0.49.32/app/src/components/MiniSidebar.tsx) supplies the 56 px black icon rail and its labels; the exhibit presents labels as text. Dynamic suggestions are omitted.
- **April, v0.53.4:** [conversation](https://github.com/tinyhumansai/openhuman/blob/v0.53.4/app/src/pages/Conversations.tsx) supplies the conditional 16 rem white `Threads` pane, `New thread`, `No threads yet`, `No messages yet` and the bottom `Type a message...` input. Its thread pane is conditional on page and welcome state.
- **May, v0.56.0:** [conversation](https://github.com/tinyhumansai/openhuman/blob/v0.56.0/app/src/pages/Conversations.tsx) retains the 16 rem pane and localized controls; [English locale](https://github.com/tinyhumansai/openhuman/blob/v0.56.0/app/src/lib/i18n/en.ts) supplies their wording.
- **June, v0.58.7:** [conversation](https://github.com/tinyhumansai/openhuman/blob/v0.58.7/app/src/pages/Conversations.tsx), [composer](https://github.com/tinyhumansai/openhuman/blob/v0.58.7/app/src/components/chat/ChatComposer.tsx), and [English locale](https://github.com/tinyhumansai/openhuman/blob/v0.58.7/app/src/lib/i18n/en.ts) supply search, the `How can I help you today?` placeholder, `Quick` / `Reasoning`, attachment and voice labels. [Token stats](https://github.com/tinyhumansai/openhuman/blob/v0.58.7/app/src/components/chat/ComposerTokenStats.tsx) shows model usage; it is not evidence of a model picker.
- **July, v0.63.9**, and **August, v0.63.7:** [July conversation](https://github.com/tinyhumansai/openhuman/blob/v0.63.9/app/src/features/conversations/Conversations.tsx), [July locale](https://github.com/tinyhumansai/openhuman/blob/v0.63.9/app/src/lib/i18n/en.ts), [August conversation](https://github.com/tinyhumansai/openhuman/blob/v0.63.7/app/src/features/conversations/Conversations.tsx), and [August locale](https://github.com/tinyhumansai/openhuman/blob/v0.63.7/app/src/lib/i18n/en.ts) retain the empty conversation and composer pattern; the conversation list is projected into the root sidebar. The similar exhibit views are intentional for the checked empty state.
- **September, v0.64.10**, and **October, v0.64.15:** [September thread](https://github.com/tinyhumansai/openhuman/blob/v0.64.10/app/src/components/assistant-ui/thread.tsx), [October thread](https://github.com/tinyhumansai/openhuman/blob/v0.64.15/app/src/components/assistant-ui/thread.tsx), and the respective [September](https://github.com/tinyhumansai/openhuman/blob/v0.64.10/app/src/lib/i18n/en.ts) and [October](https://github.com/tinyhumansai/openhuman/blob/v0.64.15/app/src/lib/i18n/en.ts) locales supply the centered `How can I help you today?`, `Send a message...`, voice and attachment controls. [September picker](https://github.com/tinyhumansai/openhuman/blob/v0.64.10/app/src/features/conversations/aui/ChatSettingsPanel.tsx) and [October picker](https://github.com/tinyhumansai/openhuman/blob/v0.64.15/app/src/features/conversations/aui/ChatSettingsPanel.tsx) place provider/model selection in the composer.

The [June](https://github.com/tinyhumansai/openhuman/blob/v0.58.7/app/src/styles/tokens.css) and [October](https://github.com/tinyhumansai/openhuman/blob/v0.64.15/app/src/styles/tokens.css) tokens specify light surface `#ffffff`, text `#171717`, line `#e5e5e5`, and dark surface `#171717`, text `#f5f5f5`, line `#262626`; the [theme state](https://github.com/tinyhumansai/openhuman/blob/v0.64.15/app/src/store/themeSlice.ts) defaults to system, so the light exhibit is one possible appearance. Earlier and later CSS applications, exact spacing and geometry, responsive behavior, account state and available model choices remain **unverified**. Other than March and September/October, the model-switch location in the pictured view is **unverified**. Attachment and voice controls open museum panels; they do not reproduce those product features. The text-mode button in April/May is only a representation. The view has not been tested in a browser.

The May sidebar also includes the sourced `All`, `Work`, `Briefing`, `Notification`, and `Workers` filters. In July and August, the separate [July thread-list component](https://github.com/tinyhumansai/openhuman/blob/v0.63.9/app/src/features/conversations/threadList/ThreadList.tsx) and [August thread-list component](https://github.com/tinyhumansai/openhuman/blob/v0.63.7/app/src/features/conversations/threadList/ThreadList.tsx) provide the search and empty-list controls. Filter and mode selections in the exhibit change their displayed selection only; there is no original service behind the reconstruction.
