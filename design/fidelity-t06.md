The [0.6.1 app](https://github.com/OpenHands/OpenHands/blob/0.6.1/frontend/src/App.tsx) specifies an initial 500px chat pane, minimum 500px widths, and a right vertical split initially positioned at the window height minus 300px. The exhibit compresses these constraints to fit the museum. The [v1.40.0 resize hook](https://github.com/OpenHands/OpenHands/blob/v1.40.0/src/hooks/use-resizable-panels.ts) defaults to a 50% left split, subject to stored state and panel visibility. The same hook was checked in the other four 2026 tags.

The [0.6.1 theme configuration](https://github.com/OpenHands/OpenHands/blob/0.6.1/frontend/tailwind.config.js) names the dark theme and primary `#4465DB`; its [app](https://github.com/OpenHands/OpenHands/blob/0.6.1/frontend/src/App.tsx) uses Tailwind neutral classes. For later tags, [v1.8.0](https://github.com/OpenHands/OpenHands/blob/v1.8.0/src/themes/color-themes.ts) defines the neutral default and [v1.40.0](https://github.com/OpenHands/OpenHands/blob/v1.40.0/src/themes/color-theme/palettes/neutral.ts) defines its neutral scale. The renderer uses matching scale values, but its exact assignment of every token to every surface is approximate.

## Limits and reviewer questions

- Exact responsive geometry, the expanded sidebar width, live state, available model names and defaults are unverified. The 2026 profile picker is conditional upstream, but the exhibit shows a representative available state for the last two editions. Its composer placeholder in those editions is left blank because the displayed default was not established.
- The 2026 right panel is represented open for comparison; its initial visibility depends on state. The overview button opens a placeholder rather than reconstructing its complete drawer. The file panel and browser/terminal content are intentionally simplified. The old configuration panel is represented by a disclosure, not a modal. File uploads, actual provider selection, and workspace operations are not implemented. The model slot uses the museum's existing model selector with no invented choices.
- The 2026 initial file panel is left blank because its precise empty state is unverified. The 2026 sidebar's plain-text product name, the museum's `Configuration` trigger, and several button placements are reconstruction accommodations. The 2024 bottom status is one possible initialized state, not a claim about every startup.
- Source-code labels can exist in translations without being displayed in every state; browser rendering, visual fidelity, responsive behavior, and exact conditional visibility were not checked. Reviewer should inspect the editions in a browser, particularly the overview and model/profile placement. The v1.16.0 and v1.24.0 screens, and the v1.34.0 and v1.40.0 screens, intentionally share their represented layout because distinct visual differences have not been established here.
- The renderer is not registered: add the import and renderer-map entry shown in the final response. `web/js/tools/index.js` is outside this task's owned files.
