### Remaining limitations

- Tabnine’s [inline-completion announcement](https://www.tabnine.com/blog/introducing-inline-code-completions/) is dated August 30, 2022, later than the catalog’s June 2022 snapshot. Earlier editions use a schematic completion example, not a verified inline or popup placement; the example and Tab control are based on later documentation. The 2021 next-generation announcement is also later contextual evidence, not proof of the June 2021 screen. Some Tabnine blog URLs redirected during direct retrieval, so their historical text was checked via the search index and should be rechecked from an archive.
- Most editions have no dated visual evidence for the exact initial state, editor chrome, typography, color, dimensions, transcript treatment, or controls. The screens are provisional approximations and do not yet satisfy a full per-version visual audit. Unknown model selectors are not fabricated.
- The completion sample and the editor code are museum-authored; the completion panel’s optional question form is museum UI, not the original Tabnine chat. The mode dropdown in newer Void editions, contextual action review, file navigation, and actual IDE operations are not implemented.
