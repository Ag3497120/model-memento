# Model Memento（日本語）

**今も触れる、AI チャットとコーディング道具の博物館。** 2022 年の ChatGPT、2025 年の Claude Code、Cursor、Codex、
OpenCode など 29 の道具を、公開されている記録から版ごとに描き直しました。モデルの選び場所も、その版で実際にあった
場所へ動きます。

**非公式です。** ロゴ・スクリーンショット・マスコット・独自の書体は使っていません。画面は文章の記録（配置・大きさ・
色の値・ボタンの名前）から描き直し、細部ごとに出典へのリンクがあります。確かめられなかった部分は画面にそう書きます。

## できること

- **版をたどる**: 29 道具・287 版。切り替えると当時の更新の演出が入り、机の時計は公開日になり、モデルの選び場所が
  当時の位置（上のメニュー、`/model`、設定の奥、`--model` で起動し直す、選べない）に移ります。
- **モデルに本人のことを聞く**: 選んだモデルが、記録（公開日・文脈長・料金・後継・頼み方）から一人称で、出典付きで
  答えます。記録にないことは「記録では確認できません」と言います。ブラウザで AI は動かしていません。
- **調べる**: 道具 5,394 件、詳しい記録のあるモデル 1,700 件余り、登録所の索引（Hugging Face 323 万件ほか）、毎日の
  ニュース、36 の会社・規格による公式のプロンプト指南 103 件と、道具ごとの指示ファイルの書き方。
- **組み合わせる**（Mac のアプリ版）: 進行役と手伝い役を別々のハーネスから選ぶと、道具のコードを変えずに作業
  フォルダーへつなぎ方を書き出します。

## 試す

- **ブラウザで**: https://ag3497120.github.io/model-memento/
- **Mac で**: `npm install` のあと `npm start`（http://localhost:5177）

## 作り方と限界

一人と AI エージェントで作っています（Claude Code が監査と統合、数十体の Codex が画面・調査・仕組みを分担）。
毎日の CI が新しいモデル・道具・ニュースを集め、AI の更新案は、出典と変更範囲を AI なしで検査してから取り込みます。

画面は当時の近似で、書体はシステムのもので代えています。答えは記録からだけで、自由な作文には答えません。
確かめたのはデスクトップの Chromium 系ブラウザだけです。
