# 15-second video (for the README and the post)

Record in one take with the built-in auto-play: open the site with `?lang=en&tour=1` (or `?lang=en&tour=1200` for 1.2 s per step).
Any key stops it. Record a window of about 1280×800 with QuickTime (Cmd+Shift+5 → Record Selected Portion), no sound.

| Time | What plays | Why it matters |
|---|---|---|
| 0–1.6 s | ChatGPT, Nov 2022: the first screen, clock at 2022-11 | instantly recognisable starting point |
| 1.6–6.4 s | ChatGPT 2023-03 → 2024-05 → 2026-11: the model picker moves, the update notice plays | the "time machine" in one glance |
| 6.4–9.6 s | Claude.ai 2023-07 → 2026-11 | a second familiar tool |
| 9.6–15 s | Claude Code 2025-05 → 2025-07, `/model` typed: the numbered list inside the terminal | the detail people comment on |
| (rest) | Cursor 2023 → 2026, OpenCode | optional for a longer cut |

Caption ideas (one line on the first frame): "Every version of ChatGPT, Claude and Claude Code, clickable — redrawn from
public records, no logos."

Before recording: dismiss nothing by hand (the tour skips the welcome), hide the browser's bookmarks bar, use the
light or dark system theme consistently.
