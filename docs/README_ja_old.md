# Model Memento

過去と現在の AI モデルを、当時のエディター・ハーネスの画面ごと呼び出して使えるラボであり、道具の博物館。
メイン画面はエディターで、上の帯でモデル（主役）と道具を別々に選びます。歴史は専用のページではなく、モデルに直接聞くと答えます。
左の列に「モデル・道具・ファイル（CLAUDE.md などの指示ファイル）・思い出（感謝・かつてのスターへの投票）・下調べ」。これからの予定は [ROADMAP.md](ROADMAP.md)、当時の道具を足す PR は [CONTRIBUTING.md](CONTRIBUTING.md)。
リポジトリにはコードだけを置き、モデルの名簿・道具の年表・人格は**その場で今の AI に調べさせて**作ります。

## 起動

```bash
npm install
npm start   # http://localhost:5177
```

API キーは要りません。手元のサブスクで動きます。

| 回線 | 使うもの | 用途 |
|---|---|---|
| Claude サブスク | Claude Code（デスクトップアプリ同梱の新しい版を優先。`CLAUDE_BIN` で指定可） | Web 検索を使う調べもの・演じ手・語り手 |
| ChatGPT サブスク | Codex CLI（ChatGPT アプリ同梱版を優先） | 演じ手・語り手 |
| ローカル | Ollama | 演じ手 |
| Claude API | `ANTHROPIC_API_KEY` がある時だけ | 上と同じ |

## その場で作るもの

データはすべて `~/.model-memento`（`MODEL_MEMENTO_HOME` で変更可）にでき、リポジトリには入りません。

| いつ | 何を | どうやって | かかる時間 |
|---|---|---|---|
| 初回起動 | 提供が終わったモデルの名簿（生没年） | 各社の提供終了ページを Web で確認。見えなかった URL は出典から外す | 2〜3 分 |
| 初回起動 | 道具とハーネスの年表 | 発表記事や変更履歴を Web で確認 | 1〜2 分 |
| 「呼ぶ」 | 即席の人格 | 演じ手自身の記憶から。確信度は 0.45 までに抑え、「記憶から」と表示 | 20〜30 秒 |
| 「深く調べる」 | 裏付けのある人格 | 論文・評価・利用者の声の Web 調査＋Hugging Face の出力データセット、三角測量、批評役 | 数分 |
| 「語らせる」 | 語り手が考える AI の歴史 | 語り手の記憶だけで語らせ、名簿と道具の年表に照らし合わせる | 1〜2 分 |

名簿にないモデルでも、名前を入れれば呼べます。図鑑からも呼べます。

## 図鑑で引ける範囲（2026-11-15 時点）

| 登録所 | 件数 | 数え方 | 静的版 |
|---|---|---|---|
| Hugging Face | 3,237,551 | サイトの表示件数 | ○（ブラウザから直接） |

| ModelScope | 289,427 | API の総数 | ×（CORS なし。手元版だけサーバーが中継） |

合計は約 442 万件（静的版では約 413 万件）。各登録所の件数は日に 1 回数え直します。

## 番付と「動かす」

- **かつてのスター番付**: Hugging Face で「いいね」の多い文章生成モデル上位 500 体から、公開から 18 か月以上たったものを並べます（いいねは、コミュニティがすでに付けた票）。▲ はここでの投票で、1 端末 1 モデル 1 票です。保存するのは端末ごとの無作為な id の SHA-256 だけです。
- **本物か再現か**: 名簿のモデルに、本物の重みのリポジトリを結びつけます（開発元のアカウントで名前の核を含み、公開日が近いもの）。見つかったモデルには「本物あり」と出ます。
- **動かす**: 右の「動かす」タブと番付から、Hugging Face のファイル一覧、`huggingface-cli download`、GGUF 版の `ollama run hf.co/…`、そのモデルを使う Spaces に飛べます。再活躍の場（使い道の例）も出します。
- **投票の保存先**: 手元版は `~/.model-memento/votes.json`。静的版は `MEMENTO_VOTES_URL`（同じ形の `/api/votes` を持つ URL）を付けてビルドすると共有され、付けないと各端末にだけ残ります。

## 当時の道具の画面

モデルを選ぶと、そのモデルが使われていた頃の道具の画面（Playground、ChatGPT、Claude.ai、Cursor、Claude Code、OpenCode、OpenClaw など 18 種・46 版）に会話欄が切り替わります。会話の上の選択で、ほかの道具・ほかの時代や Memento の標準にも切り替えられます。

- 版ごとの画面の仕様（時期・画面の種類・レイアウト・おおよその配色・その版で増えたこと・出典）は、起動時に演じ手が Web で調べて `~/.model-memento/harness.json` に作ります。調べ直すには `node scripts/harness.js`（数分）。
- オープンソースの道具は GitHub API で公開履歴を全ページ取ります（`GITHUB_TOKEN` があれば使う）。一覧 API の上限で、Codex CLI は古い分が取れていません。
- 画面はロゴやスクリーンショットを使わず、仕様からこちらの CSS で近似して描きます。右の「道具」タブに出典と版の移り変わりを出します。

## 静的版

```bash
npm run build:static   # site/ に書き出す（GitHub Pages などにそのまま置ける）
```

その時点の名簿・人格・道具の年表・語られた歴史・クローズドの一覧を `site/data/` に焼き込みます。静的版でできるのは、年表、下調べ（Vera をブラウザ内で実行）、語られた歴史の閲覧、図鑑の検索です。モデルに演じさせる・深く調べる・語らせるには、手元で `npm start` してください。`site/` は生成物なので git には入れません。

## しくみ

- `lib/backends.js` — 演じ手の差し替え口（Claude Code・Codex・Ollama・API）
- `lib/discover.js` — 名簿・道具の年表・即席の人格
- `lib/research.js`, `lib/datasets.js` — 4 方向の深い調査
- `lib/emulate.js` — なりきり。当時の文脈長・出力上限・会話形式・知識の締切は仕組みで強制し、その時代の道具を「知っていた／知らないまま一緒に働いた」に分けて演じる。演じ手ごとの補正（文体の指紋の差から作る）も
- `lib/history.js` — 語られた歴史と記録の照合
- `lib/catalog.js` — 図鑑（models.dev、Hugging Face と Spaces）

コマンドからも使えます。

```bash
node scripts/research.js claude-3-opus                      # 深く調べる
node scripts/calibrate.js claude-3-opus codex:gpt-6.1-sol   # 演じ手ごとの補正
node scripts/narrate.js codex:gpt-6.1-sol                   # 歴史を語らせる
```

出力データセットの標本は第三者が公開したデータの抜粋で、手元の `~/.model-memento` にだけ保存されます。
